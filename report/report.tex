\section*{Abstract}

This report presents a computational study of three fundamental areas of
numerical methods: interpolation, data analysis, and numerical integration.
The first project compares global polynomial interpolation using the
Lagrange formulation with a natural cubic spline constructed from the same
set of observations. The second project develops an automated Python
workflow for reading algorithm-runtime measurements from an Excel
spreadsheet, performing descriptive statistical analysis, generating
multiple visualizations, and extending the dataset with a required
$700$KB observation. The third project investigates numerical
approximation of the definite integral
$\int_0^1 e^{x^2}\,dx$ using the composite trapezoidal rule, composite
Simpson's rule, and Gauss--Legendre quadrature.

The experiments emphasize not only numerical results but also the
mathematical properties of the methods, including interpolation conditions,
smoothness, convergence order, empirical runtime behavior, and numerical
error. The interpolation experiment demonstrates the distinction between a
global high-degree polynomial and a locally defined spline representation.
The runtime analysis illustrates how numerical programming can be combined
with reproducible data-processing and visualization pipelines. The
integration experiment shows the faster convergence of Simpson's rule
relative to the trapezoidal rule and the very high accuracy achievable by
Gaussian quadrature for a smooth integrand.

All calculations and figures are generated programmatically, providing a
reproducible computational workflow. The results are interpreted
conservatively, particularly where the available dataset is insufficient
to support stronger theoretical conclusions.

\section{Introduction}

Numerical analysis provides systematic methods for obtaining approximate
solutions to mathematical problems that are difficult or impossible to
solve directly by symbolic means. Its applications extend across
engineering, physics, computer science, statistics, and applied
mathematics. Classical numerical techniques include interpolation,
numerical differentiation and integration, nonlinear equation solving,
linear algebra, and differential-equation methods
\cite{burden2010,chapra2015}.

The present project focuses on three computational tasks that illustrate
different aspects of numerical computation. The first concerns
interpolation, where an approximation is constructed from discrete data
points. The second concerns data analysis, where computational methods are
used to process and visualize measured execution times. The third concerns
numerical integration, where a definite integral is approximated through
several quadrature techniques.

The main objectives are:

\begin{enumerate}
    \item To implement Lagrange polynomial interpolation and natural cubic
    spline interpolation for a common dataset.

    \item To compare the mathematical structure and numerical behavior of
    the two interpolation approaches.

    \item To develop a reproducible workflow for reading and analyzing
    algorithm-runtime data from an Excel spreadsheet.

    \item To use descriptive statistics and multiple visualization methods
    to investigate empirical runtime behavior.

    \item To implement and compare the composite trapezoidal rule,
    composite Simpson's rule, and Gauss--Legendre quadrature.

    \item To analyze convergence and numerical error rather than relying
    solely on a single computed result.

    \item To maintain a reproducible computational project in a
    version-controlled repository.
\end{enumerate}

A central principle throughout the project is that numerical results should
be interpreted in relation to the assumptions and limitations of the
underlying methods. In particular, empirical observations should not be
mistaken for formal proofs of asymptotic complexity or exact analytical
solutions.

\section{Project 1: Interpolation Methods}

\subsection{Problem Formulation}

Interpolation estimates the value of a function at points located between
known observations. Given a set of distinct points
$(x_i,y_i)$, an interpolation function $F(x)$ is required to satisfy

\[
F(x_i)=y_i
\]

at every supplied node.

The dataset used in this experiment is

\begin{table}[H]
\centering
\caption{Interpolation Dataset}
\label{tab:interp_data}

\begin{tabular}{c|cccccc}
\toprule
$x$ & 1 & 2 & 3 & 4 & 5 & 6 \\
\midrule
$y$ & 1 & 3 & 5 & 8 & 5 & 2 \\
\bottomrule
\end{tabular}
\end{table}

Two interpolation approaches are investigated:

\begin{itemize}
    \item Lagrange polynomial interpolation.
    \item Natural cubic spline interpolation.
\end{itemize}

Classical treatments of interpolation discuss the mathematical properties,
error behavior, and limitations of polynomial and spline methods
\cite{burden2010,chapra2015}.

% ------------------------------------------------------------
% 3.1 LAGRANGE
% ------------------------------------------------------------

\subsection{Lagrange Polynomial Interpolation}

For $n+1$ distinct nodes, the Lagrange interpolation polynomial is

\[
P_n(x)
=
\sum_{i=0}^{n}
y_iL_i(x),
\]

where

\[
L_i(x)
=
\prod_{\substack{j=0\\j\neq i}}^{n}
\frac{x-x_j}{x_i-x_j}.
\]

The basis polynomials satisfy

\[
L_i(x_j)=
\begin{cases}
1, & i=j,\\
0, & i\neq j.
\end{cases}
\]

Consequently, the resulting polynomial satisfies the interpolation
conditions exactly.

For the six observations in Table~\ref{tab:interp_data}, the polynomial has
degree five:

\[
\boxed{
P(x)=
\frac{7}{40}x^5
-\frac{71}{24}x^4
+\frac{147}{8}x^3
-\frac{1249}{24}x^2
+\frac{1369}{20}x
-31
}
\]

or numerically,

\[
\begin{aligned}
P(x)={}&
0.1750x^5
-2.9583x^4
+18.3750x^3\\
&-52.0417x^2
+68.4500x
-31.
\end{aligned}
\]

The polynomial therefore satisfies

\[
P(1)=1,\quad
P(2)=3,\quad
P(3)=5,\quad
P(4)=8,\quad
P(5)=5,\quad
P(6)=2.
\]

\begin{resultbox}
\textbf{Numerical result.}
The Lagrange implementation produces a fifth-degree polynomial that
passes exactly through all six supplied interpolation nodes.
\end{resultbox}

\subsection{Natural Cubic Spline Interpolation}

A cubic spline replaces one global polynomial with a collection of cubic
polynomials defined on consecutive intervals. For
$x\in[x_i,x_{i+1}]$,

\[
S_i(x)
=
a_i(x-x_i)^3
+
b_i(x-x_i)^2
+
c_i(x-x_i)
+
d_i.
\]

A natural cubic spline satisfies interpolation, continuity of the first
derivative, continuity of the second derivative, and the natural boundary
conditions

\[
S''(x_0)=0,
\qquad
S''(x_n)=0.
\]

These conditions produce a smooth piecewise polynomial approximation
\cite{burden2010,chapra2015}.

The resulting coefficients are given in
Table~\ref{tab:spline_coefficients}.

\begin{table}[H]
\centering
\caption{Natural Cubic Spline Coefficients}
\label{tab:spline_coefficients}

\begin{tabular}{c|rrrr}
\toprule
\textbf{Interval}
& $\mathbf{a_i}$
& $\mathbf{b_i}$
& $\mathbf{c_i}$
& $\mathbf{d_i}$ \\
\midrule
$[1,2]$ & -0.1866 & 0.0000 & 2.1866 & 1.0000 \\
$[2,3]$ &  0.9330 & -0.5598 & 1.6268 & 3.0000 \\
$[3,4]$ & -2.5455 & 2.2392 & 3.3062 & 5.0000 \\
$[4,5]$ &  2.2488 & -5.3971 & 0.1483 & 8.0000 \\
$[5,6]$ & -0.4498 & 1.3493 & -3.8995 & 5.0000 \\
\bottomrule
\end{tabular}
\end{table}

For example, on the first interval,

\[
S_1(x)
=
-0.1866(x-1)^3
+
2.1866(x-1)
+
1.
\]

On the second interval,

\[
S_2(x)
=
0.9330(x-2)^3
-
0.5598(x-2)^2
+
1.6268(x-2)
+
3.
\]

The remaining intervals are defined by the coefficients in
Table~\ref{tab:spline_coefficients}.

% ------------------------------------------------------------
% 3.4 DISCUSSION
% ------------------------------------------------------------

\subsection{Discussion}

The two methods satisfy the same interpolation constraints but use different
mathematical constructions.

The Lagrange method produces one polynomial over the entire interval. This
global structure is convenient for a small number of nodes, but increasing
the polynomial degree can introduce oscillatory behavior and can make the
approximation sensitive to the node distribution.

The spline method instead uses local cubic pieces. The smoothness
constraints connect the individual pieces, while the low degree of each
piece limits the amount of global variation. This local structure is one
reason cubic splines are widely used for practical interpolation
\cite{burden2010}.

It is important to note that the present experiment contains only six
points. Therefore, the figure demonstrates the behavior of the two methods
for this particular dataset and should not be interpreted as a universal
benchmark.

\subsection{Runtime Interpretation}

The measurements indicate three distinct empirical performance levels.

Algorithm 1 is consistently the fastest of the three algorithms in the
observed range. Algorithm 2 has a larger runtime but maintains a regular
increase with input size. Algorithm 3 produces the largest values at the
higher input sizes.

However, these observations should not be converted directly into
asymptotic complexity statements. The theoretical complexity of an
algorithm depends on the algorithmic operations and their scaling with
input size, not merely on a small number of measured execution times.

Therefore, the appropriate conclusion from this dataset is that the
algorithms demonstrate different empirical runtime trends over the tested
range. A stronger complexity analysis would require repeated measurements,
larger input ranges, controlled hardware conditions, and knowledge of the
underlying algorithms.

\section{Project 3: Numerical Integration}

\subsection{Problem Formulation}

The third project evaluates

\[
I=
\int_0^1e^{x^2}\,dx.
\]

The integrand

\[
f(x)=e^{x^2}
\]

is smooth on $[0,1]$, but it does not possess an elementary
antiderivative. Numerical quadrature is therefore a natural computational
approach.

The following methods are compared:

\begin{enumerate}
    \item Composite trapezoidal rule.
    \item Composite Simpson's rule.
    \item Gauss--Legendre quadrature.
\end{enumerate}

The comparison emphasizes convergence and absolute error.

% ------------------------------------------------------------
% REFERENCE
% ------------------------------------------------------------

\subsection{Reference Value}

Because no elementary antiderivative is available, the project uses a
high-accuracy numerical value computed using
\texttt{scipy.integrate.quad} as a reference. The SciPy documentation
describes \texttt{quad} as a definite-integration routine based on the
QUADPACK library \cite{scipy_quad,piessens1983}.

The reference value obtained is

\[
\boxed{
I_{\mathrm{ref}}
\approx
1.462651745907181
}
\]

This quantity is a high-accuracy numerical reference and is not claimed to
be an elementary exact analytical value.

% ------------------------------------------------------------
% TRAPEZOIDAL
% ------------------------------------------------------------

\subsection{Composite Trapezoidal Rule}

For $n$ equally spaced subintervals,

\[
h=\frac{b-a}{n}.
\]

The composite trapezoidal approximation is

\[
T_n
=
\frac{h}{2}
\left[
f(a)+f(b)
+
2\sum_{i=1}^{n-1}f(x_i)
\right].
\]

For sufficiently smooth functions, the global truncation error is of
order

\[
O(h^2)
\]

\cite{burden2010,chapra2015}.

% ------------------------------------------------------------
% SIMPSON
% ------------------------------------------------------------

\subsection{Composite Simpson's Rule}

For even $n$,

\[
S_n
=
\frac{h}{3}
\left[
f(a)+f(b)
+
4\sum_{\substack{i=1\\i\text{ odd}}}^{n-1}
f(x_i)
+
2\sum_{\substack{i=2\\i\text{ even}}}^{n-2}
f(x_i)
\right].
\]

For sufficiently smooth functions, the global truncation error is of order

\[
O(h^4),
\]

which explains the faster convergence observed in the experiment
\cite{burden2010,chapra2015}.

% GAUSSIAN

\subsection{Gauss--Legendre Quadrature}

Gaussian quadrature approximates an integral by selecting nodes and weights
that provide high-order accuracy.

After mapping the standard interval $[-1,1]$ to $[a,b]$,

\[
x=
\frac{b-a}{2}t+
\frac{a+b}{2},
\]

the approximation is

\[
I
\approx
\frac{b-a}{2}
\sum_{i=1}^{n}
w_i
f
\left(
\frac{b-a}{2}t_i+
\frac{a+b}{2}
\right).
\]

For the implementation, Gauss--Legendre nodes and weights are used. The
method is particularly effective for smooth integrands
\cite{press2007,chapra2015}.

\section{Cross-Project Discussion}

The three experiments address different mathematical tasks but illustrate
several common principles of numerical computing.

\subsection{Approximation and Reference Values}

Interpolation provides an exact fit at known nodes but does not guarantee
that the interpolating function equals an unknown underlying function
between those nodes.

Numerical integration introduces a different approximation problem. The
computed quadrature result is an approximation to a definite integral, and
the present experiment uses a high-accuracy numerical computation as a
reference.

Consequently, numerical analysis requires careful distinction between
mathematical exactness and numerical accuracy.

\subsection{Convergence as a Diagnostic Tool}

A single numerical result does not provide enough information to assess the
quality of a numerical method. Convergence experiments are more informative
because they reveal how the result changes when the computational
resolution is increased.

The integration experiment demonstrates this directly. The trapezoidal
and Simpson approximations progressively approach the reference value,
while Gaussian quadrature achieves rapid error reduction as the number of
nodes increases.

\subsection{Global Versus Local Approximation}

The interpolation experiment illustrates the difference between a global
representation and a local representation.

Lagrange interpolation produces a single global polynomial. Cubic spline
interpolation instead constructs local cubic pieces joined through
smoothness constraints.

This distinction is important in numerical modeling because local methods
can reduce the influence of distant observations and avoid some undesirable
behavior associated with high-degree global approximations.

\subsection{Data Analysis as a Numerical Workflow}

The Excel experiment demonstrates that practical numerical computing
includes considerably more than implementing mathematical formulas.

A reliable computational workflow should also address:

\begin{itemize}
    \item input validation,
    \item data-type consistency,
    \item reproducible transformations,
    \item statistical summaries,
    \item visualization,
    \item automated output generation, and
    \item protection against duplicate or inconsistent updates.
\end{itemize}

The automatic $700$KB insertion is a small but concrete example of this
principle.

\section{Limitations and Future Work}

\subsection{Interpolation}

Only six observations are available. Future experiments could compare the
methods using larger datasets and different node distributions, including
uniformly spaced and non-uniformly spaced nodes.

The interpolation error could also be measured against a known analytical
function rather than only comparing the resulting curves.

\subsection{Runtime Analysis}

The runtime dataset is intentionally small and therefore cannot establish
formal asymptotic complexity.

A more rigorous performance study would repeat each algorithm multiple
times, use a wider range of input sizes, control system conditions, report
measurement variability, and investigate the relationship between input size
and runtime using appropriate statistical models.

\subsection{Numerical Integration}

The function $e^{x^2}$ is smooth and well behaved on the selected interval.
Additional experiments involving discontinuities, singularities,
oscillatory functions, or rapidly varying functions would provide a more
comprehensive assessment of the numerical integration methods.

\section{Conclusion}

This project implemented and evaluated numerical techniques for
interpolation, computational data analysis, and numerical integration.

The interpolation experiment showed that both Lagrange interpolation and
natural cubic splines can reproduce the supplied observations exactly, but
their underlying constructions differ. Lagrange interpolation provides a
single global polynomial, whereas cubic splines use locally defined cubic
pieces connected through smoothness conditions.

The Excel analysis demonstrated a reproducible computational workflow for
loading, validating, analyzing, visualizing, and updating structured data.
The three visualization techniques provide complementary perspectives:
bar charts emphasize direct comparison, line charts emphasize trends, and
box plots summarize distributions.

The numerical integration experiment provided the clearest quantitative
comparison of convergence. Simpson's rule substantially outperformed the
trapezoidal rule at the tested subdivision levels, while Gauss--Legendre
quadrature achieved extremely high accuracy using a small number of
evaluation points for the smooth integrand under consideration.

More broadly, the project demonstrates that effective numerical computing
requires a combination of mathematical theory, careful implementation,
quantitative error analysis, visualization, and reproducibility. The
results should therefore be interpreted not merely as numerical answers,
but as evidence of the computational behavior of the implemented methods
under clearly specified experimental conditions.
